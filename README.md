# 📱 Smartphone Price Predictor (V1)

A Machine Learning web application that predicts the estimated price of a smartphone based on its specifications.

> 🚧 **Current Version: V1**
>
> This is the first version of the project. It focuses on building and deploying a machine learning model capable of estimating smartphone prices based on user-provided specifications. Future versions will introduce improved prediction accuracy, value-for-money recommendations, and live price comparison across online retailers.

---

## ✨ Features

- 🤖 Machine Learning-based smartphone price prediction
- 📊 Estimates market price from smartphone specifications
- 🌐 Interactive web interface built with Flask
- ⚡ Instant prediction generation
- 📱 User-friendly input form
