# 📱 Forge – Smart Smartphone Price Predictor

> **An end-to-end Machine Learning web application that predicts smartphone prices based on their specifications using a trained regression model.**

Forge combines Machine Learning with a modern web interface to provide quick and accurate smartphone price predictions. Built with **Python, Scikit-learn, Flask, and React**, the project demonstrates the complete ML workflow—from data preprocessing and model training to backend API development and frontend deployment.

---

## 🚀 Live Demo

🌐 **Website:** https://forge-smart.vercel.app

## 📌 Overview

Buying or selling a smartphone can be confusing without knowing its fair market value.

Forge solves this problem by allowing users to enter a smartphone's specifications and instantly receive an estimated price generated by a trained Machine Learning model.

The project demonstrates an end-to-end ML pipeline including:

* Data preprocessing
* Feature engineering
* Model training
* Model serialization
* REST API development
* Frontend integration
* Deployment

## 📂 Dataset

The model was trained on a cleaned smartphone dataset containing **3,260 smartphones** with **15 selected features**, including:

* Brand
* RAM
* Storage
* Operating System
* Battery Capacity
* Processor Brand
* Number of CPU Cores
* Rear Camera Specifications
* Front Camera Specifications
* Display Size
* Display Type
* Fast Charging Support

The dataset was carefully cleaned by removing highly incomplete features and handling missing values before training.

## 📈 Model Performance

| Metric                         | Score         |
| ------------------------------ | ------------- |
| R² Score                       | **0.72**      |
| Mean Absolute Error (MAE)      | **≈ ₹7,120**  |
| Root Mean Squared Error (RMSE) | **≈ ₹11,687** |

These results indicate that the model captures the overall pricing trends effectively while maintaining reasonable prediction accuracy across a wide range of smartphone specifications.
